আমার মতো মানুষ — বাস্তব-ডেটা ম্যাচিং সংস্করণ

এই প্যাকেজে ওয়েবসাইটের ফ্রন্টএন্ড এবং Node.js + SQLite ব্যাকএন্ড আছে। মিলের স্কোর এবং “৮০% বা তার বেশি মিল থাকা ব্যবহারকারী” কেবল ডেটাবেসে সম্মতি দিয়ে উত্তর জমা দেওয়া প্রকৃত ব্যবহারকারীদের হিসাব থেকে আসে। কোনো কৃত্রিম সংখ্যা বানিয়ে দেখানো হয় না।

গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি এখনো ইন্টারনেটে প্রকাশিত/হোস্ট করা হয়নি। ZIP ফাইল নিজে নিজে পাবলিক ওয়েবসাইট নয়।
- বাস্তব ক্রস-ইউজার ম্যাচিং চালাতে Node.js সার্ভার ও স্থায়ী SQLite ডেটাবেসসহ হোস্টিং দরকার। শুধু index.html ফোনে খুললে API কাজ করবে না।
- নতুন সাইটে প্রথম ব্যবহারকারীর জন্য তুলনা করার মতো কেউ নাও থাকতে পারে; তখন স্কোর “নতুন” দেখাবে, সংখ্যা হবে ০।
- মিলের সূত্র: ৬টি উত্তরকে ওজন দিয়ে তুলনা করা হয়। একই উত্তর ১০০%, একটি ধাপ পার্থক্য প্রায় ৬৭%, দুই ধাপ প্রায় ৩৩%, তিন ধাপ ০%; ৮০% বা তার বেশি হলে মিল হিসেবে গণনা। ডেটাবেস বড় হলে ফল বদলাতে পারে।
- ডেটা সংরক্ষণ স্পষ্ট সম্মতির পরে হয়। নাম/ফোন/ইমেইল/সঠিক আয় সংগ্রহ করা হয় না। PRIVACY.md পড়ে হোস্ট করার আগে নিজের যোগাযোগ ও ডেটা-রিটেনশন নীতি যোগ করুন।

সার্ভারে চালানোর নিয়ম
1. কম্পিউটারে Node.js 20 বা নতুন সংস্করণ ইনস্টল করুন।
2. এই ফোল্ডারটি কম্পিউটারে Extract করুন।
3. টার্মিনাল/কমান্ড প্রম্পটে এই ফোল্ডারে যান।
4. চালান: npm install
5. চালান: npm start
6. ব্রাউজারে খুলুন: http://localhost:3000

অনলাইনে চালু করতে
- Node.js অ্যাপ চালাতে পারে এমন হোস্টিং বেছে নিন।
- SQLite ফাইল রাখার জন্য persistent disk/volume দিন; ephemeral filesystem ব্যবহার করলে ডেটা হারাতে পারে।
- HTTPS চালু করুন, ডেটাবেস ব্যাকআপ ও মুছে ফেলার অনুরোধের ব্যবস্থা রাখুন।
- PRIVACY.md-কে নিজের বাস্তব তথ্য দিয়ে সম্পূর্ণ করুন। GDPR ও প্রযোজ্য আইন যাচাই করুন।

নিজের ক্রেডিট নাম বদলাতে index.html-এ এই লাইনটি সম্পাদনা করুন:
const CREATOR_NAME = "আপনার নাম";

API
GET /api/health — সার্ভার চলছে কি না
POST /api/profiles — সম্মতিসহ উত্তর সংরক্ষণ ও মিল গণনা
GET /api/stats — সংরক্ষিত প্রোফাইলের মোট সংখ্যা
DELETE /api/profiles/me — X-Delete-Token হেডার দিয়ে নিজের প্রোফাইল মুছুন
